# cloud-trustworthiness-irnam
Implementing "Intelligent Recommendation &amp; Negotiation Model (2023)" paper

## Cloud Provider Dataset & QoS Management

**Contributor:** Anurag

### Objective
Developed the cloud provider dataset and preprocessing module for the IRNAM recommendation system.

### Work Completed
- Created cloud dataset for AWS, Azure, and GCP.
- Included QoS parameters: Cost, Availability, Reliability, Security, Scalability, Response Time, Throughput, and Support Quality.
- Implemented `data_collection.py` for loading the dataset.
- Implemented `preprocessing.py` for preprocessing and normalization.
